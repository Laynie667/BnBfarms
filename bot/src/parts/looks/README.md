# Looks

What somebody looks like, and lines that fit it.

| File | What's in it |
|---|---|
| 10c-outfits.js | outfits, and ?ownoutfit |
| 10r-looks.js | what somebody's wearin' that the lines should notice (tails, for now) |
| 10s-marks.js | real marks on a character, done by their own Companion (only with "Farm can mark my body" on) |
| 10un-outfit-wheel.js | the outfit wheel |
| 10uq-brand.js | the farm's brand |
| 10y9d-body-fit.js | lines that fit the body they're about (`bodyOf`) |
| 10y9e-farm-look.js | the farm's look for the drawn body |
| 10y9h-gear-sense.js | what somebody's got on, so a line fits their gear (`gearSense`) |

The build joins every part by file name, not folder: see [the parts README](../README.md).
