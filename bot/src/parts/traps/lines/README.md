# Trap lines

The bigger line pools for the traps. Each list here is added onto the pool of the same name.

| File | What's in it |
|---|---|
| 10u2-trap-lines.js | the traps' first lines |
| 10w-trap-lines-more.js | more trap lines |
| 10w2-trap-lines-deeper.js | deeper trap lines |
| 10w3-lines-wider.js | more of everything the traps say |
| 10w4-lines-creatures.js | the creatures in the traps, first half |
| 10w5-lines-creatures-more.js | the creatures, second half |
| 10w6-lines-traps-core.js | the core traps' lines |
| 10x2-extra-lines-wider.js | more for the trap extras |
| 10z2-trap-variant-lines.js | lines for the trap variants |
| 10z3-variant-lines-wider.js | more for the variants |

The build joins every part by file name, not folder: see [the parts README](../../README.md).
